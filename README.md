# 🛒 README — Plataforma de Ventas Online (En desarrollo)

## 📌 Descripción del Proyecto

Este proyecto es una **página web de ventas online**, diseñada para presentar productos de manera clara, responsiva y visualmente atractiva. Está enfocada en usabilidad, estructura limpia y buenas prácticas desde la base.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript**
* **Git / GitHub**

---

## ✨ Características (Actuales y Planeadas)

* ✔️ Estructura inicial del sitio
* ✔️ Diseño responsivo base
* 🔄 Catálogo de productos
* 🔄 Página de detalles por producto
* 🔄 Carrito de compras básico
* 🔄 Interfaz visual organizada
